# LightRetaggio

KiCad project for the LightRetaggioSchema board (LightController breakout), migrated from the original Eagle design.

## Repository layout

- `kicad/` — the active KiCad project (KiCad 10.0)
  - `LightRetaggioSchema.kicad_pro` — project file, open this in KiCad
  - `LightRetaggioSchema.kicad_sch` — schematic
  - `LightRetaggioSchema.kicad_pcb` — PCB layout
  - `LightRetaggioSchema-eagle-import.kicad_sym` — symbol library generated by the Eagle import
  - `LightRetaggioSchema.pretty/` — footprint library extracted from the imported board, registered in `fp-lib-table`
  - `sym-lib-table`, `fp-lib-table` — project-local library tables (paths are relative, no extra setup needed)
- `LightRetaggioSchema.sch` / `.brd` / `.pro` — original Eagle source (kept for reference)
- `LightRetaggioSchema_2020-04-23.zip` — archived Eagle export
- `eagle.epf` — Eagle workspace file

## Requirements

- [KiCad 10.0](https://www.kicad.org/download/) or newer

## Setup / build instructions

1. Install KiCad 10.0+.
2. Clone this repository:
   ```
   git clone https://github.com/Rocco83/LightRetaggio.git
   cd LightRetaggio
   ```
3. Open `kicad/LightRetaggioSchema.kicad_pro` in KiCad. The symbol and footprint libraries are referenced with relative paths in `sym-lib-table` / `fp-lib-table`, so no library setup is required beyond opening the project.
4. To edit: open the schematic (Eeschema) or PCB (Pcbnew) from the KiCad project manager.
5. To regenerate manufacturing outputs:
   - Gerbers/drill: Pcbnew → File → Fabrication Outputs → Gerbers / Drill Files
   - BOM: Eeschema → Tools → Generate Bill of Materials
   - Pick-and-place: Pcbnew → File → Fabrication Outputs → Component Placement Files

## Notes on the migration

The board was imported from the original Eagle source (rev V1.2, 2021-04-19) using KiCad's combined Eagle project importer. The importer generates a symbol library but no footprint library, so the footprints embedded in the imported board were extracted into `kicad/LightRetaggioSchema.pretty/` and registered under the `LightRetaggioSchema` nickname.

Verified clean after migration:
- **DRC**: 0 unconnected items, 0 footprint errors (remaining violations are cosmetic silkscreen/text sizing rules KiCad enforces more strictly than Eagle did)
- **ERC**: remaining violations are expected (unused switch pins, NC optocoupler pins, and a VCC/GND dual-net-naming convention already approved in the original Eagle file)

The original Eagle files (`.sch`, `.brd`, `.pro`) are kept at the repository root for reference/history.
